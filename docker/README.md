# docker/

Reserved for containerization assets: `Dockerfile`s for the frontend
and backend, `docker-compose.yml` wiring up the app with MySQL, Redis,
and RabbitMQ, and any container-specific config.

Docker is listed under "Future Technologies" for this project and is
intentionally **not** implemented in Sprint 1 (Project Setup). This
folder exists now so the structure is stable and later sprints have
an obvious home for these files.
